# Roadmap

This roadmap is exploratory. A stage advances only when its evidence requirements are met.

## v0.1 — Public conceptual prototype
- Publish the core metaphor and model boundaries.
- Define provisional routing questions.
- Document observation, expiry, counterevidence, and open questions.
- Invite criticism and counterexamples.

## v0.2 — Minimal interoperable schema
- Test the minimal record format.
- Define provenance and expiry fields.
- Separate observations from interpretations.
- Add examples from lawful, shareable sources.

Exit condition: independent contributors can create and interpret records without undocumented assumptions.

## v0.3 — Evaluation protocol
- Preregister comparison against simpler baselines.
- Define topic/time-window splits.
- Measure reviewer agreement and next-observation usefulness.
- Test counterexamples and out-of-time generalization.
- Report failures and unknowns.

Exit condition: a reproducible evaluation demonstrates a specific, bounded benefit — or shows the framework adds no value.

## v0.4 — Reference implementation (optional)
Only if the schema and evaluation justify it: build a small reference tool with inspectable provenance, expiry, correction, and deletion.

No release date or performance target is promised.
