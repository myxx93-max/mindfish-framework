# Research Status and Evidence Boundaries

**Mindfish v0.1 is a conceptual research prototype.** This repository publishes a framing, provisional vocabulary, and evaluation questions. It does not publish a validated production algorithm.

## Source-grounded history

- The user-defined concept was described as an abstract tool for hotspot work: helping decide which direction is worth observing, supplementing, verifying, or acting on.
- It must not be interpreted literally or as a fixed psychological/personality classification.
- The original metaphor: water = real-world information environment; flow = attention migration and collective tension; fish = changing cognitive states; hooks = unresolved contradictions; floats = observable traces; net = evidence environment.
- Attention Flow was positioned as prioritization and temporal background, not a substitute for factual evidence, safety, or publication authorization.
- Earlier local Mindfish/hot-router work described its model as a `STARTING HYPOTHESIS`, not business truth. Reproducibility within a local experiment does not establish predictive accuracy, causal validity, or business utility.
- An earlier Attention Flow M1 result was invalidated due to target-geometry problems. Subsequent clean-target work must be evaluated independently.
- No production integration or externally validated performance is claimed here.

## Evidence labels

- `SOURCE_OBSERVED` — source directly inspected and its contents recorded.
- `REPRODUCED` — a specified procedure was rerun with a reproducible artifact.
- `SUPPORTED` — independent evidence supports a narrowly stated claim.
- `CONTESTED` — material evidence conflicts with the claim.
- `UNKNOWN` — evidence is absent, insufficient, or ambiguous.
- `HYPOTHESIS` — a testable proposal not yet established.

Do not promote a claim merely because a script ran or a test passed.

No private comment corpus, user identifiers, account information, credentials, or unpublished production code is included.
