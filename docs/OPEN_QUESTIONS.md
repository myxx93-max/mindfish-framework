# Open Research Questions

## Conceptual validity
1. What distinguishes a Mindfish hypothesis from a topic, intent, sentiment, narrative, or information need?
2. Does the fish metaphor add operational value, or is a simpler vocabulary better?
3. Are GAP, FOLLOW, VERIFY, STAKE, ACTION, and EXPRESS useful routing questions? Which should be merged or removed?
4. Can a hypothesis be defined precisely enough to be falsified?

## Temporal validity
5. What observation window is appropriate for different topics?
6. How can recurrence be distinguished from a continuous state?
7. Is hysteresis necessary, and can it be preregistered without overfitting?
8. When should a hypothesis expire?

## Evidence and evaluation
9. What counts as an independent source?
10. How should source coverage, selection bias, deletion, and missingness be represented?
11. Can independent reviewers agree on the same hypothesis and next direction?
12. Does Mindfish improve the next-observation choice compared with keyword search, trend ranking, or a simpler issue taxonomy?
13. Can it improve out-of-time performance without future information?
14. Which counterexamples should force a hypothesis to be split or abandoned?

## Human and social boundaries
15. How can topic-level analysis avoid person-level profiling?
16. How should minority or low-volume voices be represented?
17. Which data should never be collected or published?
18. How can a community challenge an interpretation or request removal?
